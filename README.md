# Лабораторна робота №3
## Реалізація обробки винятків та створення власних підкласів Exception

### Предметна область

Предметна область лабораторної роботи — фітнес-клуб.

Основна сутність предметної області — клієнт фітнес-клубу (`Client`).

Клієнт має такі характеристики:
- ім'я;
- прізвище;
- вік;
- тип абонемента;
- кількість місяців;
- вартість одного місяця.

Програма дозволяє вводити дані клієнтів, виводити список клієнтів, знаходити кількість клієнтів з абонементом від 6 місяців, сортувати клієнтів за вартістю місячного абонемента та виконувати пошук клієнта.

### Реалізація обробки винятків

У лабораторній роботі реалізовано:

- обробку `InputMismatchException` при некоректному введенні числових даних;
- обробку `NegativeArraySizeException` при введенні від'ємної кількості клієнтів;
- використання блоку `finally` для гарантованого закриття `Scanner`;
- створення власного checked-виключення `DomainException`;
- створення підкласів `InvalidAgeException` та `InvalidSubscriptionException`;
- передачу повідомлення через `super(message)`;
- збереження некоректного значення у власному полі `invalidValue`;
- самостійне збудження власних винятків за допомогою `throw`;
- множинну обробку винятків за допомогою декількох `catch`;
- повторне збудження `InputMismatchException` за допомогою `throw e`;
- ієрархію власних винятків.
