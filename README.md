# JavaFitnessClub
# ЛР1. Фітнес-клуб

## Предметна область

Фітнес-клуб — облік клієнтів та абонементів.

## Сутності

### Клієнт
- ім'я;
- прізвище;
- вік.

### Абонемент
- тип абонемента;
- кількість місяців;
- вартість одного місяця.

## Опис програми

Програма отримує дані клієнта та його абонемента.

Розраховується загальна вартість абонемента.

Якщо абонемент придбано на 6 або більше місяців, надається знижка 10%.

## Використані типи даних

- `String` — ім'я, прізвище, тип абонемента;
- `int` — вік, кількість місяців;
- `double` — вартість.

## Запуск

Компіляція:

    javac Main.java

Запуск:

    java Main
